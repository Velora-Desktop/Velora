# Источники логотипов рейтингов

Оригинальные монохромные SVG получены из открытого набора
[Simple Icons](https://github.com/simple-icons/simple-icons), лицензия CC0-1.0:

- Metacritic
- IGN
- IMDb
- Кинопоиск
- Rotten Tomatoes
- Letterboxd
- CNET

Для PC Gamer, GameSpot, DualShockers, PCMag, TechRadar и Tom's Guide,
отсутствующих в используемой версии Simple Icons, созданы компактные
локальные SVG-wordmark-варианты в визуальном стиле Velora.

`source_press.svg` является нейтральной резервной иконкой для редких
профессиональных изданий. Она не подменяет фирменный знак и всегда
показывается рядом с настоящим названием источника.
