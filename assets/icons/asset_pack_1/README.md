# Velora Asset Pack 1.0

Подготовленный набор ассетов для интеграции в существующий Velora IconProvider/IconRegistry.

- Простые монохромные PNG из исходной коллекции переведены в SVG по силуэту исходного изображения.
- Исходные PNG сохранены в `originals/mycollection/` для визуальной проверки и отката.
- GIF Netflix и бюджета оставлены GIF: предполагается воспроизведение только при hover.
- Логотипы Amediateka, Kinopoisk и Premier оставлены в исходных форматах.
- Brand содержит dark/light/color варианты.
- `manifest.json` задаёт semantic ID и физический путь.

Важно: перед удалением исходных PNG в проекте сравнить SVG с originals на реальных размерах UI (16/20/24/32 px). Если конкретная трассировка хуже оригинала, IconProvider должен использовать original PNG или существующий качественный SVG.
