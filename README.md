# Velora AW0.09 — в разработке

Новый цикл разработки после завершённой публичной альфы AW0.07. Velora объединяет игры, фильмы, сериалы и программы, хранит личные данные локально и использует отдельно обновляемый официальный каталог.

Текущий официальный каталог: `AW0.099` (400 карточек: по 100 игр, фильмов, сериалов и программ). Описания локализованы, а оценки показывают понятные названия профессиональных источников вместо технических ID.

## Возможности AW0.09

- умные системные и пользовательские списки без копирования объектов;
- единая лента локальной активности;
- пользовательские цели; теги назначаются непосредственно на странице объекта;
- аналитика расхождения личной и общей оценок;
- сравнение текущего и предыдущего периодов;
- снимок профиля и статистики в PNG.
- очередь «Что дальше» с приоритетами, датами и drag-and-drop;
- локальный рандомайзер показывает пять кликабельных вариантов выбранного типа;
- локальные черновики, редактируемые шаблоны обзоров и дневник впечатлений;
- архив и безопасная корзина без потери истории;
- стартовый блок «Сегодня» и отдельная умная библиотека;
- локальные пользовательские разделы и карточки через верхнюю кнопку `+`, изолированные от официального каталога.

## Основа AW0.08

- единый каталог четырёх типов контента;
- личные оценки по критериям, статусы, избранное и хронология;
- локальный профиль и отдельная пользовательская SQLite-база;
- Quick View и канонические страницы объектов по стабильному `catalog_id`;
- личная статистика, глобальный поиск и фильтрация;
- безопасное скрытие контента 18+;
- единая тёмная визуальная система и официальный набор SVG-иконок.
- проверяемый экспорт и полный импорт локальной резервной копии;
- автоматические копии перед миграциями и восстановлением;
- диагностика SQLite, локальные журналы и сведения о размере хранилища;
- отдельные метрики игр, фильмов, сериалов и программ;
- минимальные и рекомендуемые системные требования;
- расширенный набор категорий и Velora Icon Pack v2.

## Запуск

```powershell
python -m pip install -r requirements.txt
python main.py
```
