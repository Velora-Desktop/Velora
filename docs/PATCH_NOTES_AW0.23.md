# Velora AW0.23 — новый цикл разработки

## Asset Pack 1.0

- Новый набор жанровых, технических, сервисных и фирменных ресурсов встроен в
  существующие `IconRegistry`, `IconProvider` и Velora UI Kit без параллельной
  системы иконок.
- Жанры левой панели и технические поля карточки используют semantic keys с
  безопасным fallback на прежние ресурсы.
- Добавлен единый hover-компонент для Netflix и бюджета, foundation
  reduced-motion и ненарушающий layout pulse избранного.
- Фирменные и сервисные изображения сохраняют исходные цвета; монохромные SVG
  поддерживают централизованный tint и кэширование.
- Journey Completion Pass намеренно не продолжался до завершения проверки
  Asset Pack.

## Journey Completion Pass

- Персональные состояния, оценки, настроение и флаги этапов переведены на
  явные проекции `user.db`; официальный шаблон Journey остаётся в каталоге.
- Завершение текущего этапа атомарно переводит следующий незаполненный этап в
  состояние «Текущий»; последний этап не завершает прохождение без подтверждения.
- Timeline показывает только пользовательские события со стабильными типами и
  явным `stage_id`; технические события хранения скрыты.
- Добавлены контексты этапа, отдельного события и группы событий, а также
  безопасное редактирование и удаление через append-only историю.
- События размещаются между этапами; ширина сегмента зависит от количества
  событий, при переполнении используется компактный индикатор `+N`.
- Статистика Journey рассчитывается по явным оценкам, настроению, флагам и
  видимым событиям выбранного прохождения. Время из интерфейса Journey убрано.
- Read model истории всех прохождений расширен данными, необходимыми будущему
  Creator, без зависимости от выбранного состояния UI.

## Journey Micro Polish 01B — прохождения

- Селектор прохождений переведён на стабильные `playthrough_id` и надёжно
  работает с длинной историей без ограничения в десять записей.
- Кнопка нового прохождения создаёт отдельную запись через application
  service; этапы, оценки, настроение, впечатления и события прежних
  прохождений сохраняются.
- Левая карточка показывает контекст «Текущее / Первое прохождение /
  Повторное прохождение», время только выбранного прохождения и дату
  последней активности в человекочитаемом формате.
- Добавлен read-only агрегат истории всех прохождений для будущих Creator и
  аналитики: суммарное время, оценки, этапы, moods, события и заметки.
- `catalog.db` и официальный Journey template этим патчем не изменяются.

## Journey Compact Reference Rebuild

- Journey помещается в карточку игры без вложенной вертикальной прокрутки.
- Маршрут, выбранный этап и аналитика приведены к утверждённым Full HD
  пропорциям.
- Постоянный большой редактор заменён контекстными модальными формами.
- Добавлены явные личные состояния этапов с хранением только в `user.db`.
- Статус этапа и оценка 1–10 доступны непосредственно в Journey.
- Маршрут рисуется единым timeline canvas; карточки и события прокручиваются
  синхронно.

## Journey Reference Match Pass

- Journey приведён к утверждённой композиции: карточка прохождения,
  горизонтальная лента, единый дневник этапа и трёхчастная аналитика.
- Удалены режимы сетки/списка; навигация выполняется стрелками с удержанием,
  клавиатурой и горизонтальной полосой прокрутки.
- Этапы и быстрые действия используют общие компоненты Velora UI Kit.
- Добавлены отдельные стабильные `mood_id`; настроение хранится только в
  `user.db` и не выводится из числовой оценки.
- Предварительная оценка учитывает только заполненные этапы и показывает
  нейтральное состояние при отсутствии данных.
- Подготовлены визуальные smoke-снимки основных размеров и состояний Journey.

## Journey Pixel Match Pass

- Геометрия Journey пересобрана по утверждённому референсу, а не уменьшена
  ради помещения всех блоков в один экран.
- Добавлена общая вертикальная прокрутка вкладки при компактной высоте.
- Стрелки ленты стали компактными; карточки, события и соединители движутся
  в одной горизонтальной системе координат.
- Детальная карточка получила три устойчивые области: этап, впечатления и
  быстрое добавление.
- Mood selector показывает фирменные SVG-настроения без технического ComboBox.
- Аналитика разделена на самостоятельные метрики, увеличенный MoodChart и
  валидируемую предварительную оценку.

## Velora UI Kit 1.0

- Добавлен независимый от данных UI Kit с едиными semantic tokens.
- Этапы Journey, быстрые действия и график переведены на общие компоненты.
- Добавлен централизованный semantic IconProvider с безопасным fallback.
- Системные emoji и случайные Unicode-иконки удалены из постоянного Journey UI.
- Добавлен Journey Mood Pack со стабильными ID и общим MoodChart.
- Зафиксированы правила расширения компонентов, иконок и настроений.

Статус: открыт локально.

## Правила цикла

- Новые изменения записываются в этот документ по мере реализации.
- Личные данные пользователя не включаются в официальный каталог.
- Изменения каталога готовятся под номером `AW0.231` и публикуются только при
  отдельном завершении цикла.
- Схема пользовательской базы и стабильные идентификаторы не меняются без
  отдельного утверждённого этапа.

## Journey Redesign

- Существующая вкладка Journey переработана без создания второго экрана и
  без изменения Schema 1 или application services.
- Добавлена единая горизонтальная лента крупных этапов с событиями,
  состояниями и плавной прокруткой; переключатели сетки и списка отсутствуют.
- Слева отображается выбранное прохождение, его прогресс, время и дата начала.
- Детальная область этапа объединяет дневник впечатлений, оценку, теги и
  карточки быстрого добавления событий.
- Добавлена мотивирующая нижняя аналитика: статистика прохождения, график
  настроения и предварительная оценка по заполненным этапам.
- Все сохранения по-прежнему проходят через существующий Journey adapter и
  сервисы AW0.2; новые элементы не выполняют прямых записей в SQLite.
- Официальная структура Journey теперь читается из типизированного
  `journey_template` payload каталога, подготовленного Studio; встроенный
  шаблон используется только как безопасный fallback.
- Оценки этапов, впечатления, заметки и связанные пользовательские события
  не входят в официальный payload и продолжают храниться локально в
  `user.db`.
- В карточке игры добавлено устойчивое переключение «Об игре / Journey»:
  обе страницы переиспользуют одни и те же виджеты без пересоздания.
- Актуальное прохождение выбирается автоматически; завершённое последнее
  прохождение остаётся доступным для заполнения впечатлений и оценок.
- Селектор показывает номер каждого сохранённого прохождения и позволяет
  возвращаться к архивным прохождениям без смешивания их данных.
- В горизонтальную линию Journey добавлены отдельные стрелки и плавная
  прокрутка к выбранному этапу.
- В «Мой Velora» добавлена вкладка Journey со входом в личную историю игры.

## Journey Micro Polish 01C — удаление прохождения

- В левой карточке прохождения добавлено компактное меню действий с безопасным
  удалением выбранного прохождения.
- Перед удалением показывается полное предупреждение о связанных персональных
  данных; действие выполняется только после явного подтверждения.
- Удаление проходит атомарно через application service и Unit of Work только в
  `user.db`; официальный каталог и Journey template не изменяются.
- После удаления выбирается предыдущее прохождение, а при его отсутствии —
  следующее. Для последнего прохождения показывается штатное пустое состояние.
- Исторические номера не переиспользуются и не перенумеровываются: после
  удаления №2 из последовательности №1–№3 новое прохождение получит №4.
- Удалённое прохождение исключается из времени, рейтингов, mood history,
  событий, впечатлений и агрегированной статистики Creator/history.
