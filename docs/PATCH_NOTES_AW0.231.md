# Velora AW0.231 — обложки каталога игр

AW0.231 завершает локальное заполнение обложек существующего игрового каталога.

## Хронологии и аудит качества каталога

- Канонические обложки каталога перенесены во все связанные узлы хронологий.
- Для внешних игр добавлено 196 локальных обложек; итоговое покрытие хронологий
  составляет 273/301. Оставшиеся 28 узлов не получили случайных изображений;
  сомнительные источники сохранены в `manual_review`.
- Хронология Dishonored полностью получила локальные обложки.
- Проведена выборочная проверка 20 игр разных типов: фиксированный Journey не
  назначается sandbox, multiplayer и нелинейным играм без подтверждённой модели.
- Полный Journey/description backfill не объявлен завершённым: текущий Schema 1
  publish bridge поддерживает только Doom Eternal. Подробности — в
  `docs/implementation/AW0.231_CATALOG_QUALITY_BACKFILL_REPORT.md`.

## Что изменилось

- Проведён аудит всех 100 игровых карточек `catalog.db`.
- Для 90 карточек без изображения добавлены проверенные вертикальные обложки.
- В приоритете использованы официальные материалы Steam и Microsoft/Xbox; для игр без подходящей магазинной страницы применены точные box-art конкретных изданий.
- Все обложки сохранены локально в `assets/covers/catalog` и не зависят от интернет-соединения во время работы Velora.
- Изображения нормализованы в существующий формат каталога: JPEG, 300×450, без растяжения пропорций.
- Добавлен проверяемый manifest источников и SHA-256 для новых файлов.

## Безопасность данных

- Изменён только официальный `catalog.db` и каталог ресурсов обложек.
- `user.db`, пользовательские оценки, Journey и локальные медиа не изменялись.
- Схема базы данных не менялась.

## Результат

- Игровых карточек: 100.
- Валидных локальных обложек: 100.
- Отсутствующих или повреждённых обложек: 0.

## Известные ограничения

- Патч заполняет только уже существующие игровые карточки. Для будущих карточек обложка должна добавляться вместе с данными каталога.
- Источники загрузки сохранены для аудита, но Velora отображает только локальные файлы.
# Journey catalog second pass

- Проверены все 101 активная игровая карточка.
- Реальные упорядоченные этапы подготовлены для 13 однозначно подтверждённых кампаний.
- Для 55 игр назначены подходящие Journey Templates без выдуманных этапов.

## Catalog Master Data Repair

- Все 101 активная игровая карточка включена в единый field-level QA manifest.
- Исправлено 100 подтверждённых значений года, разработчика и издателя без смены stable ID.
- Устранены смешения одноимённых игр, ремейков и данных киноадаптаций.
- Все 101 обложка повторно проверены как локальные и читаемые.
- Сомнительные engines, требования, chronology, Journey и company-logo mappings не
  угадывались: они вынесены в отдельный `manual_review`.
- Schema 1 и пользовательские данные не изменялись.
