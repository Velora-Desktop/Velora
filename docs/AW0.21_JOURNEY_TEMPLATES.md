# Journey Templates AW0.21

Journey Template — это UI-neutral правило интерпретации уже существующих
данных Schema 1. Шаблон не хранит вторую историю и не изменяет доменное ядро.

Поток данных:

`DoomDetailState → JourneyPresentationBuilder → JourneyTemplateRegistry → JourneyPresentation → JourneyView`

Реестр содержит 21 пользовательский шаблон. Они собираются из общей временной
структуры, модели этапов и прогресса, модификаторов, обязательных и
необязательных блоков и правил извлечения источников Creator.

Новый шаблон добавляется декларативной записью в registry. Для него не нужен
новый backend или отдельный набор виджетов.
