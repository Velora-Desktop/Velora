# AW0.23 Journey Completion Check

## Что проверено

- Создание, переключение и удаление прохождений, сохранение исторических номеров и изоляция данных разных прохождений.
- Статусы прохождения `planned`, `playing`, `completed`, `abandoned` и их существующее отображение в интерфейсе.
- Состояния этапов `not_started`, `current`, `in_progress`, `completed`; клик по status icon и атомарное продвижение следующего этапа в `current`.
- Отсутствие обязательного ручного времени этапа в Journey при сохранении общего playtime приложения.
- Независимость rating, mood, favorite и difficult; отсутствие оценки представляется как `None`.
- CRUD и проекция восьми пользовательских типов событий: заметка, скриншот, достижение, любимый момент, музыка, сложный момент, впечатление и другое.
- Фильтрация технических storage-событий, размещение пользовательских событий на Timeline, `+N`, Context Viewer и быстрое добавление.
- Аналитика выбранного прохождения: признаки этапов, заметки, события, Mood Chart и среднее только по явно оценённым этапам.
- End-to-end сценарий: создание прохождения → завершение этапа → автоматический `current` следующего этапа → rating → mood → favorite/difficult → создание и изменение события → повторное открытие storage.
- Персональные Journey-данные сохраняются в `user.db`; байты `catalog.db` до и после end-to-end сценария совпадают.
