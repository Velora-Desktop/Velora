# AW0.231 Catalog Deep Verification

Дата проверки: 2026-08-12.

## Что проверено

Работа выполнена только по существующей очереди `data/aw0231_catalog_manual_review.json`. Для точной идентификации использованы `catalog_id`, название и год конкретного издания. Проверенные источники сохранены у каждого finding и в `deep_verification` файла `data/aw0231_catalog_master_audit.json`.

Приоритет источников: официальные страницы Steam для издания, затем PCGamingWiki. Значения без достаточного подтверждения не переносились в `catalog.db`.

Исправлено или подтверждено:

- официальные player modes из категорий storefront;
- официальные Minimum/Recommended PC requirements;
- 20 достоверно названных игровых движков;
- 65 собственных русских описаний уровня карточки Velora;
- дополнительные developer/publisher/release year при точном совпадении издания;
- требования нормализованы в контракт Schema 1: `os_min`, `cpu_min`, `ram_min`, `gpu_min`, `storage_min` и соответствующие `_rec`;
- удалён несовместимый промежуточный формат `minimum/recommended` с двумя HTML-блоками.

`user.db`, Schema 1, stable IDs, Journey UI и официальный Journey rollout не изменялись.
