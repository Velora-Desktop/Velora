# AW0.231 — Journey catalog second pass

## Результат

Проверены все 101 активная игровая карточка каталога. Каждая получила одно из
явных решений в `data/aw0231_journey_backfill.json`:

- `publish_ready` — назначен шаблон и сохранены реальные упорядоченные этапы;
- `template_assigned` — назначен корректный шаблон, но этапы не выдумываются;
- `manual_review` — структура или метаданные требуют ручного решения;
- `not_applicable` — официальный линейный Journey не отражает устройство игры.

Итог: 13 `publish_ready`, 55 `template_assigned`, 16 `manual_review`,
17 `not_applicable`.

Отдельные `God of War` 2005 и 2018 сопоставляются по стабильным catalog ID, а
не по названию, поэтому их этапы не конфликтуют.

## Границы

В каталог не публиковались фиктивные этапы. `template_assigned` означает, что
generic bridge уже знает тип Journey, но список официальных этапов должен быть
подтверждён отдельным контентным проходом. `user.db` не открывался и не
изменялся.
