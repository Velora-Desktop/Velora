# AW0.23 Journey Compact Reference Rebuild

## Результат

Существующая вкладка Journey пересобрана как компактный экран без внутренней
вертикальной прокрутки. На Full HD три постоянные зоны занимают 628 px:

- маршрут — 295 px;
- выбранный этап — 195 px;
- аналитика — 122 px;
- два промежутка по 8 px.

Постоянный `JourneyQuickEditor` удалён из композиции. Основной экран оставляет
только обзор маршрута, прямую оценку этапа, короткое превью воспоминания и
восемь карточек быстрого добавления. Полная форма открывается единым
`JourneyEntryDialog` только по выбранному действию.

## Архитектура и данные

- В `user.db` добавлена личная таблица `journey_stage_states`.
- Состояние этапа хранится явно: `not_started`, `current`, `in_progress`,
  `completed`, `skipped`.
- `catalog.db` не изменяется и не содержит личных состояний.
- Запись идёт через `DoomAw02Panel` → `DoomVerticalSlice` →
  `UserUnitOfWork` → `JourneyStageStateRepository`.
- Для старых профилей таблица создаётся идемпотентным AW0.23 extension hook.
- Старые записи продолжают отображаться благодаря presentation fallback;
  новое действие пользователя сразу фиксирует явное состояние.

## UI-компоненты

- `JourneyTimelineCanvas` рисует единую непрерывную линию, соединители и узлы
  в одном scroll content.
- `VeloraStageCard` содержит отдельную интерактивную status icon; клик по
  остальной карточке только выбирает этап.
- `VeloraRatingSelector` переиспользован для прямой оценки 1–10.
- `JourneyEntryDialog` переиспользуется для восьми типов личных событий.
- Легенда собрана отдельными SVG-иконками через `IconProvider`, без emoji.

## Проверка

- Полный regression suite: **185 tests, OK**, 2 устаревших теста постоянного
  quick editor отмечены как skipped после удаления этого UI-контракта.
- `compileall app velora_contracts tests`: success.
- `git diff --check`: success (только уведомления Git о будущей нормализации
  LF/CRLF).
- Проверено отдельно: повторная запись состояния, отклонение неизвестного
  состояния и отсутствие личной таблицы в `catalog.db`.

  записи нет собственного media reference.
