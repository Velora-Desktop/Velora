# AW0.231 — HoverAnimatedIcon hotfix

## Причина

При быстром уничтожении строки каталога Qt мог доставить уже поставленное в
очередь hover-событие фильтру `HoverAnimatedIcon`. Python-обёртка ещё
существовала, но соответствующий C++ `QLabel` уже был удалён. Вызов базового
`eventFilter()` или обновление кадра после этого приводили к нестабильному
падению полного набора тестов.

## Исправление

- перед обработкой hover и timer callback проверяется валидность Qt-объекта;
- фильтр не вызывает C++ base implementation после собственной обработки;
- autoplay не участвует в hover-фильтрации;
- добавлен regression test с уничтожением owner до доставки события.

Hotfix не меняет визуал, assets, базы данных или контракты Journey.
