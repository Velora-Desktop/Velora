# Journey Mood Pack

Настроение представлено стабильным ID из `MoodRegistry`. UI и будущая
персистентность используют `happy`, а не «Радость», путь к SVG или emoji.
Display name, tooltip, вес графика, цвет и icon key принадлежат
`MoodDefinition`.

Оценка и настроение независимы. `MoodChartPoint` хранит оба значения отдельно;
`score_weight` используется только для вертикального положения mood point.
Если настроение отсутствует, график показывает нейтральную точку и может
сохранить существующую rating projection.
