# Ограничения Schema 1 в AW0.21

Schema 1 не изменялась.

Доступно постоянно: прохождения, checkpoints, impressions, ratings и immutable
Journey events. Вычисляется в read model: стадии, ключевые моменты, структура
шаблона и Creator Source Model.

Только в текущей сессии живут Creator marks и выбранная конфигурация preview в
Studio. Для постоянных Creator marks в будущем потребуется отдельное
нормативное решение Schema 2; AW0.21 его не маскирует.
