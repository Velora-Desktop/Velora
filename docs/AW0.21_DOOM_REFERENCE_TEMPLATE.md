# Doom Eternal Reference Template

Doom Eternal использует композицию:

- Story Campaign;
- Arena Shooter modifier;
- mission stages;
- combat encounters;
- collectibles;
- boss moments;
- Creator extraction rules.

Карточка остаётся адаптером существующего AW0.2 vertical slice. Центральный
Journey строится универсальными моделями и виджетами, поэтому решение применимо
к будущим карточкам без Doom-специфичного backend.
