# Velora AW0.3

AW0.3 — большой функциональный релиз Velora. Главная часть цикла — Journey 1.0 и единая визуальная инфраструктура приложения.

## Journey

- В карточке игры появилась постоянная вкладка Journey.
- Один универсальный интерфейс работает с динамическим количеством этапов и официальными Journey Templates.
- Timeline объединяет карточки этапов и пользовательские события между ними; большие группы сворачиваются в `+N`.
- Поддерживаются несколько независимых прохождений: создание, переключение, удаление, сохранение выбора и отдельный прогресс.
- Этапы имеют состояния, completion с автоматическим переходом к следующему этапу, rating и независимый mood.
- Доступны заметки, впечатления, скриншоты, достижения, любимые и сложные моменты, музыка и другие события через Quick Add.
- Context Viewer позволяет выбирать, просматривать, изменять и удалять события без пересоздания всей страницы.
- Mood Chart и статистика прохождения используют только данные выбранной игры и выбранного прохождения.
- Данные сохраняются после перезапуска и изолированы между играми.

## Interface

- Добавлен Velora UI Kit 1.0 с едиными цветами, типографикой, интервалами, радиусами и размерами.
- Journey использует переиспользуемые карточки, rating-компоненты и Mood Pack.
- Улучшены состояния загрузки, пустых данных и ошибок без изменения общей тёмной стилистики Velora.

## Icons & Assets

- Введены IconRegistry и IconProvider с семантическими идентификаторами и безопасным fallback.
- Расширены SVG-наборы жанров, metadata, сервисов и Journey.
- Постоянный Journey UI больше не зависит от системных emoji.
- Интегрированы локальные логотипы компаний с источниками Wikimedia Commons.

## Animations

- Добавлена общая motion-система для hover-анимаций, scale/opacity и favorite pulse.
- Звезда избранного делает короткое увеличение и возвращается к исходному размеру без сдвига layout.
- Поддерживаются reduced motion и безопасное завершение Qt-анимаций.
- Исправлен lifecycle race анимированных иконок.

## Game Cards

- Обновлена структура Game Detail и улучшены metadata blocks.
- Journey, статистика и chronology стали согласованными частями карточки.
- Обновлено представление developer/publisher и добавлена общая Asset System.

## Technical Improvements

- Official Journey хранится в `catalog.db`; playthrough, progress, rating, mood, events и notes — в `user.db`.
- Doom Eternal остаётся эталонной карточкой, но runtime Journey использует универсальный pipeline.
- Studio 0.2 публикует official Journey через общий контракт без Doom-specific ветки.

## Fixes

- Исправлены повторные визуальные артефакты, нестабильные обновления Timeline и сохранение выбранного контекста.
- Добавлена защита от отсутствующих SVG и завершения animation callbacks после удаления widget.
