# Journey → Creator

`CreatorSourceBuilder` получает `JourneyPresentation`, а не читает Qt-виджеты.
Каждый источник имеет стабильный `source_id`, тип, текст, этап, время, оценку и
порядок. Creator placeholder может получить реальную игру, прохождение и
категории источников без чтения UI.

Начиная с эталонного UX AW0.21 ручные отметки «Использовать в Creator»
отменены. Все релевантные материалы автоматически входят в
`CreatorSourceModel`; дальнейший отбор будет выполняться внутри будущего
Creator. Schema 1, скрытая таблица и второй backend не создавались.
