# Velora AW0.21 — новый UX-цикл

AW0.21 развивает готовое ядро AW0.2. Contracts 1, Catalog 0.21,
`user.db Schema 1`, пользовательские данные и безопасные границы хранения
остаются без изменений.

## Цель цикла

- завершить «Мой Velora»;
- сделать Doom Eternal эталонной карточкой игры;
- определить универсальное пользовательское представление Journey;
- выделить повторяемые элементы карточки в переиспользуемые компоненты;
- подготовить структуру данных, которую позднее сможет описывать Studio.

## Уже зафиксировано

- верхняя навигация «Мой Velora»: Обзор, Ассистент, Creator, Мои оценки,
  Избранное и Статистика;
- профиль встроен в «Обзор»;
- умные списки, цели, теги и аналитика вкуса собраны в «Ассистенте»;
- Creator занимает постоянное место в интерфейсе, но остаётся заглушкой;
- Doom Eternal остаётся единственной вертикалью нового ядра.

## Не входит в цикл

- Creator Backend;
- AI-рекомендации;
- DOCX Export;
- новая схема базы данных;
- облачная синхронизация;
- массовое подключение остальных игр;
- полноценная аналитика вкуса.

## Статус

Цикл открыт локально. Первый законченный UX эталонной карточки реализован
для Doom Eternal и проходит визуальную проверку.
Git commit, Git tag и публикация на GitHub не выполнялись.

## Стабилизация верхней панели карточки

- Статус игры переведён на единый постоянный компонент для каталога, Quick View и полной карточки.
- При смене статуса компонент больше не пересоздаётся и не получает новый stylesheet.
- Устранены отдельные непрозрачные поверхности интерактивных ячеек: фон выделения и наведения теперь рисует только строка целиком.
- Кликабельное название строки больше не использует нативную поверхность кнопки Windows.
- Действие изменения общего времени получило явное фиолетовое hover/focus-состояние.
- Переход из Quick View на полную страницу закреплён только за названием объекта; пассивные области и меню действий больше не дублируют переход.
- Добавлена стресс-проверка многократной смены статуса, изменения размеров и повторного применения темы.

## Эталонный UX Journey

- Старые вкладки «Обзор / Прохождения / Journey / Впечатления / Оценки»
  объединены в одну рабочую область.
- Journey перестроен из технического журнала в горизонтальный путь из
  13 миссий Doom Eternal.
- Этапы получили завершённое, текущее, будущее и выбранное состояния;
  заполненная линия растёт вместе с прохождением.
- Выбранный этап раскрывается в одной стабильной карточке и редактируется
  через компактный inline-сценарий: статус, оценка, впечатление, сохранение.
- Добавлен компактный переключатель повторных прохождений; архивные
  прохождения защищены от случайной записи.
- Ручные действия передачи в Creator удалены. Все релевантные материалы
  Journey автоматически входят в `CreatorSourceModel`.
- Горизонтальная прокрутка ограничена Timeline; вертикальную прокрутку
  контролирует основная страница игры.
- Doom Eternal получила короткое описание игрового опыта вместо длинного
  энциклопедического текста.
- Компоновка проверена на ширине 1280, 1600 и 1920 пикселей.
- Убраны контрастные чёрные подложки внутри системных требований и
  хронологии: вложенные области используют единый фон карточек Velora.
- Системные требования и хронология перенесены ниже блока
  «Оценки и источники».
- Личный ряд со статистикой, критериями оценки и историей изменений
  расположен сразу после оценок, перед системными требованиями.
- Поле `DirectX / API` удалено из отображения системных требований Velora и
  из редактора Studio; строка «Дополнительно» поднята на его место.
# Journey и эталонная карточка

- Добавлен универсальный реестр из 21 Journey Template.
- Реализован read-model поток от данных AW0.2 к Journey Presentation.
- Doom Eternal получила эталонную конфигурацию Story Campaign + Arena Shooter.
- Journey стал центральным интерактивным блоком карточки.
- Подходящие события автоматически формируют источник будущего Creator.
- Creator остаётся отдельной заглушкой и не требует ручных marks в Journey.
- Studio получила каталог и preview шаблонов Journey без изменения Schema 1.
